# РКСИ Расписание — Android

Оболочка на WebView: интерфейс в `app/src/main/assets/index.html`, запросы к rksi.ru идут через `MainActivity` (без CORS).
Те же возможности, что в десктопе: «Моя группа», «Разовый выбор» с фильтрами (группа + преподаватель + предмет + дни недели),
«Статистика» (часы по дисциплинам, 1 пара = 1 час), темы Авто / Светлая / Тёмная / Чёрная, обнаружение изменений.

## Сборка APK
**Android Studio:** File → Open → папка проекта, дождаться синхронизации, Build → Build APK(s).
Результат: `app/build/outputs/apk/debug/app-debug.apk`. Скопируйте на телефон и разрешите установку из неизвестных источников.

**GitHub:** залейте папку в репозиторий — workflow `.github/workflows/android.yml` соберёт APK (раздел Actions → Artifacts).

Не проверено на устройстве: интерфейс проверен в Chromium, а сборка Gradle и работа моста Java↔JS не запускались.
